pixel-drawing Documentation

Introduction

pixel-drawing is a Rust library for software rendering onto raw RGBA pixel buffers. It provides glyph rasterization, icon rendering, text layout, progress bars, and a builder-pattern render context — all without requiring a windowing system or GPU. Colors use the generic Color<T> type from smearor-commons-color (Color<f64> normalized, Color<u8> pixel-native).

What Does It Do?

  • Pixel Operations — fill_background, blend_pixel, and a bitmap text fallback renderer
  • Glyph Rendering — Single-glyph rasterization with alpha blending using ab_glyph, plus glyph-to-pixel scale computation with caching
  • Icon Rendering — Draw Nerd Font icons by name or codepoint, icon placeholders, and icon grids
  • Text Rendering — Draw label text at the bottom of an image or centered text at arbitrary positions, with font fallback chains and truncation
  • Progress Bars — Horizontal progress bar rendering with configurable colors
  • RenderContext — Builder pattern that combines background fill, icon drawing, and label text into a single fluent API

Getting Started

Prerequisites

Rust

A working Rust toolchain is required. The project uses Rust Edition 2024.

curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

Minimum Supported Rust Version (MSRV)

The crate declares rust-version = "1.85" in its Cargo.toml. The MSRV is verified by CI on every push and pull request.

System Dependencies

The crate requires nerd-fonts-gtk with render and embed-fonts features, which bundle font files and use ab_glyph for rasterization. No system libraries are required beyond a Rust toolchain.

If you use the interactive_demo example (GTK4), you need GTK 4 development libraries:

Ubuntu/Debian:

sudo apt-get install -y pkg-config libgtk-4-dev libglib2.0-dev

Installation

From Source

git clone https://github.com/smearor/pixel-drawing.git
cd pixel-drawing
cargo build --release

As a Dependency

Since pixel-drawing depends on nerd-fonts-gtk via a path dependency, add both to your workspace:

[dependencies]
pixel-drawing = { path = "../pixel-drawing" }
nerd-fonts-gtk = { path = "../nerd-fonts-gtk", default-features = false, features = ["render", "embed-fonts"] }

Quick Start

Fill and Draw an Icon

#![allow(unused)]
fn main() {
use pixel_drawing::pixel_buffer::PixelBuffer;
use pixel_drawing::size::Size;
use smearor_commons_color::Color;

let mut buf = PixelBuffer::new(Size::new(96, 96));
buf.fill_background(Color::<f64>::new(0.1, 0.1, 0.1));
buf.draw_nerd_font_icon(
    "nf-fa-gamepad",
    true,
    |name| Some('\u{F11B}'),
    Some(Color::<f64>::new(0.4, 0.7, 1.0)),
);
}

Using RenderContext

#![allow(unused)]
fn main() {
use pixel_drawing::pixel_buffer::PixelBuffer;
use pixel_drawing::render_context::RenderContext;
use pixel_drawing::size::Size;
use smearor_commons_color::Color;

let mut buf = PixelBuffer::new(Size::new(96, 96));
let mut ctx = RenderContext::new(&mut buf)
    .background(Color::new(0.12, 0.12, 0.12))
    .icon_color(Color::new(0.4, 0.7, 1.0))
    .active(true);
ctx.fill_background();
ctx.draw_icon('\u{F11B}');
ctx.draw_label("gamepad");
}

Design Principles

No Windowing System Required

All rendering functions operate on raw &mut [u8] RGBA pixel buffers. This makes the library suitable for headless rendering, texture generation, and embedded use cases.

Font Dependency

pixel-drawing delegates font loading to nerd-fonts-gtk:

  • nerd_font() — Nerd Font for icon glyphs
  • label_font() — Label font for text rendering

This separation keeps font bundling and loading logic in one place while pixel-drawing focuses on pixel-level rendering.

Alpha Blending

All glyph and text rendering uses alpha blending via blend_pixel. Source pixels are composited over destination pixels with per-pixel alpha coverage from ab_glyph’s outline rasterizer.

Caching

glyph_fit_scale uses a thread_local cache keyed by (GlyphId, target_px) to avoid redundant glyph probing on repeated renders of the same icon at the same size.

Data Flow

graph LR
    Font["nerd_fonts_gtk::fonts::nerd_font()"]
    Glyph["glyph_fit_scale"]
    Draw["draw_glyph"]
    Blend["blend_pixel"]
    Pixels["&mut [u8]"]

    Font --> Glyph
    Glyph --> Draw
    Draw --> Blend
    Blend --> Pixels
  1. Font is loaded via nerd_font() (cached in nerd-fonts-gtk)
  2. glyph_fit_scale computes the em-scale for a target pixel size
  3. draw_glyph rasterizes the glyph outline with ab_glyph
  4. blend_pixel composites each pixel with alpha blending
  5. Result is written directly into the caller’s pixel buffer

Pixel Operations

PixelBuffer provides low-level pixel buffer manipulation methods.

fill_background

Fills the pixel buffer with a solid color. Accepts any type that implements Into<Color<u8>>, so both Color<f64> and Color<u8> work:

#![allow(unused)]
fn main() {
use pixel_drawing::pixel_buffer::PixelBuffer;
use pixel_drawing::size::Size;
use smearor_commons_color::Color;

let mut buf = PixelBuffer::new(Size::new(64, 64));
buf.fill_background(Color::<f64>::new(0.2, 0.5, 0.8));
}

The buffer is interpreted as row-major RGBA (4 bytes per pixel). If the underlying buffer is larger than width * height * 4, only the expected region is filled.

blend_pixel

Composites a source color over a destination pixel with alpha blending:

#![allow(unused)]
fn main() {
use pixel_drawing::drawing::blend_pixel;

let dst = [10, 20, 30, 255];
let src = [255, 0, 0, 255];
let result = blend_pixel(&dst, &src, 128);
}

This is used internally by draw_glyph and is not typically called directly.

draw_text_bitmap

A fallback bitmap text renderer used when no font is available. It renders text using a built-in 5x7 bitmap font. This is primarily used as a last-resort fallback by draw_label_text and draw_text_centered.

Glyph Rendering

The drawing::glyph module provides single-glyph rasterization and font metric utilities. These are used internally by the icon and text rendering methods on PixelBuffer and are not typically called directly.

glyph_fit_scale

Computes the em-scale needed so that a glyph’s largest dimension equals a target pixel size. Nerd Font symbols typically occupy only a small fraction of the em square, so a 76px em can produce a ~12px glyph. This function probes the glyph at a reference scale and computes the correct em-scale.

Results are cached in a thread_local AHashMap keyed by (GlyphId, target_px) to avoid redundant probing on repeated renders.

#![allow(unused)]
fn main() {
use nerd_fonts_gtk::fonts::nerd_font;
use pixel_drawing::drawing::glyph::glyph_fit_scale;

let font = nerd_font().unwrap();
let glyph_id = font.glyph_id('\u{F11B}');
let scale = glyph_fit_scale(font, glyph_id, 48.0);
}

draw_glyph

Rasterizes a single glyph onto the pixel buffer with alpha blending. Uses ab_glyph’s outline rasterizer and composites each pixel via blend_pixel. This is a PixelBuffer method called internally by the text and icon rendering methods.

truncate_text_to_width

Truncates text to fit within a maximum pixel width, using incremental width tracking (O(n) in the number of characters). Returns the truncated string.

Icon Rendering

PixelBuffer provides methods to draw Nerd Font icons onto pixel buffers.

draw_nerd_font_icon

Draws a Nerd Font icon centered in the upper portion of the image. The icon name is resolved to a codepoint via a caller-provided resolver function. If the font or icon is unavailable, a circular placeholder is drawn instead.

#![allow(unused)]
fn main() {
use pixel_drawing::pixel_buffer::PixelBuffer;
use pixel_drawing::size::Size;
use smearor_commons_color::Color;

let mut buf = PixelBuffer::new(Size::new(96, 96));
buf.draw_nerd_font_icon(
    "nf-fa-gamepad",
    true,
    |name| Some('\u{F11B}'),
    Some(Color::<f64>::new(0.4, 0.7, 1.0)),
);
}

Parameters:

  • icon_name — Nerd Font icon name (e.g. "nf-fa-gamepad")
  • is_active — affects default color when icon_color is None
  • resolve_codepoint — function mapping icon names to char codepoints
  • icon_color — optional color; falls back to default_text_color(is_active)

draw_icon_placeholder

Draws a simple circular placeholder when the font or icon is unavailable:

#![allow(unused)]
fn main() {
use pixel_drawing::pixel_buffer::PixelBuffer;
use pixel_drawing::size::Size;

let mut buf = PixelBuffer::new(Size::new(32, 32));
buf.draw_icon_placeholder(false);
}

draw_nerd_font_codepoint

Draws a Nerd Font icon by its Unicode codepoint at a custom position and size:

#![allow(unused)]
fn main() {
use pixel_drawing::pixel_buffer::PixelBuffer;
use pixel_drawing::size::Size;
use smearor_commons_color::Color;

let mut buf = PixelBuffer::new(Size::new(64, 64));
buf.draw_nerd_font_codepoint(
    '\u{F11B}',
    32.0, 32.0, 48.0,
    Color::<u8>::new(255, 255, 255),
);
}

Accepts impl Into<Color<u8>>, so both Color<f64> and Color<u8> work.

draw_icon_grid

Draws a 2x2 or 3x3 icon grid within the image area. Each icon is centered in its cell:

#![allow(unused)]
fn main() {
use pixel_drawing::pixel_buffer::PixelBuffer;
use pixel_drawing::size::Size;

let icons = ["nf-fa-gamepad", "nf-fa-star", "nf-fa-heart", "nf-fa-bug"];
let mut buf = PixelBuffer::new(Size::new(192, 192));
buf.draw_icon_grid(
    &icons, 2, true,
    |name| Some('\u{F11B}'),
);
}

Text Rendering

PixelBuffer provides methods to render text onto pixel buffers using ab_glyph, with font fallback chains.

draw_label_text

Draws a text label at the bottom of the image using the label font. Falls back to the Nerd Font if the label font is unavailable, and to a bitmap renderer if no font is available.

#![allow(unused)]
fn main() {
use pixel_drawing::pixel_buffer::PixelBuffer;
use pixel_drawing::size::Size;
use smearor_commons_color::Color;

let mut buf = PixelBuffer::new(Size::new(96, 96));
buf.draw_label_text(
    "gamepad",
    true,
    Some(Color::<f64>::new(0.9, 0.9, 0.9)),
);
}

The text is automatically truncated to fit within 90% of the image width.

draw_text_centered

Draws text centered horizontally at a given y-baseline with a configurable font size:

#![allow(unused)]
fn main() {
use pixel_drawing::pixel_buffer::PixelBuffer;
use pixel_drawing::size::Size;
use smearor_commons_color::Color;

let mut buf = PixelBuffer::new(Size::new(128, 64));
buf.draw_text_centered(
    "Hello",
    32.0, 16.0,
    Color::<u8>::new(255, 255, 255),
);
}

Accepts impl Into<Color<u8>> for the color parameter, so both Color<f64> and Color<u8> work.

Font Fallback Chain

  1. label_font() — primary label font (loaded from bundled WOFF2)
  2. nerd_font() — Nerd Font as fallback
  3. draw_text_bitmap — built-in 5x7 bitmap font as last resort

Truncation

Both methods use truncate_text_to_width to ensure text fits within 90% of the buffer width. Characters are added incrementally until the next character would exceed the maximum width.

Progress Bars

PixelBuffer provides a progress bar rendering method with shared color defaults.

draw_progress_bar

Draws a horizontal progress bar at the bottom of the image:

#![allow(unused)]
fn main() {
use pixel_drawing::pixel_buffer::PixelBuffer;
use pixel_drawing::size::Size;
use smearor_commons_color::Color;

let mut buf = PixelBuffer::new(Size::new(256, 32));
buf.draw_progress_bar(
    0.65,
    Color::<f64>::new(0.4, 0.7, 1.0),
);
}

The bar is 4 pixels high, positioned 2 pixels from the bottom. The fill width is proportional to value (clamped to [0.0, 1.0]). Unfilled portions use a dimmed version of the color (each channel divided by 3).

Accepts impl Into<Color<u8>> for the color parameter.

default_text_color

Returns the default text color based on active state:

  • Active: Color::<u8>::new_rgba(100, 180, 255, 255) — blue
  • Inactive: Color::<u8>::new_rgba(240, 240, 240, 255) — light gray

This function is used internally by draw_nerd_font_icon, draw_icon_grid, and draw_label_text when no explicit color is provided.

RenderContext

RenderContext is a builder pattern that encapsulates the pixel buffer, dimensions, and default colors, then provides methods that delegate to the methods on PixelBuffer.

Basic Usage

#![allow(unused)]
fn main() {
use pixel_drawing::pixel_buffer::PixelBuffer;
use pixel_drawing::render_context::RenderContext;
use pixel_drawing::size::Size;
use smearor_commons_color::Color;

let mut buf = PixelBuffer::new(Size::new(96, 96));
let mut ctx = RenderContext::new(&mut buf)
    .background(Color::new(0.12, 0.12, 0.12))
    .icon_color(Color::new(0.4, 0.7, 1.0))
    .active(true);
ctx.fill_background();
ctx.draw_icon('\u{F11B}');
ctx.draw_label("gamepad");
}

Configuration Methods

These methods consume self and return a new RenderContext, enabling chaining during construction:

MethodDescription
background()Sets the background fill color
icon_color()Sets the default icon/progress bar color
text_color()Sets the default text label color
active()Sets the active state (affects default colors)

Drawing Methods

These methods take &mut self and write to the pixel buffer:

MethodDescription
fill_background()Fills the buffer with the configured background
draw_icon()Draws an icon by codepoint
draw_icon_by_name()Draws an icon by name (requires resolver function)
draw_label()Draws label text at the bottom
draw_text()Draws centered text at a given y-baseline
draw_progress_bar()Draws a progress bar with the configured color

Example: Icon with Label

#![allow(unused)]
fn main() {
let mut buf = PixelBuffer::new(Size::new(96, 96));
let mut ctx = RenderContext::new(&mut buf)
    .background(Color::new(0.1, 0.1, 0.1))
    .icon_color(Color::new(0.9, 0.3, 0.4))
    .active(true);
ctx.fill_background();
ctx.draw_icon_by_name("nf-fa-heart", resolve_codepoint);
ctx.draw_label("heart");
}

Default Colors

If not configured, the defaults are:

  • icon_color: Color::<f64>::new(0.94, 0.94, 0.94) — light gray
  • text_color: Color::<f64>::new(0.94, 0.94, 0.94) — light gray
  • is_active: false
  • background: None (no fill)
